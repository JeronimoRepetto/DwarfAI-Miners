# S-008-1 — license record per bundled adapter or library

Stub record of `21-migration-plan.md` §2 P-4 (spike wave 1, long-lead). The check has not run: this file names its
owner and what it gates, and records no result. `17-testing-strategy.md` §4 does not count it as the record that
closes the spike.

## Question

Spike register S-008-1 (ADR-008 item 1; ADR-009 D5; `15-provider-driver.md` §2.4, §8): for each bundled adapter or
library (`codex-acp`, the Kimi SDK, the ACP TS SDK), the license, redistribution permission and GPL-3.0-or-later
compatibility, its NOTICE and attribution obligations, and the version-pinning policy. The Claude Agent SDK and
`claude-agent-acp` are out of scope: never bundled (OQ-52, AMENDMENT-2).

## What it gates

- Bundling each package as an app dependency (OQ-48 A, OQ-52). Until it passes for a package, an executable adapter
  (`codex-acp`) is installed by the user, and an in-process library (Kimi SDK, ACP TS SDK) cannot be, so the drivers
  that need it are not offered (`15` §2.4).
- Step 3a entry for the ACP TS SDK, as the other path to a Claude driver beside SP-08 (`21` §9); before Kimi and Kiro
  enter the catalog, for the Kimi SDK; and v1: closed for every bundled package (`21` §8 R-06, §9).
