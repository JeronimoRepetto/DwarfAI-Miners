# S-024-1 — display facts for Veta's `displayKey`

## Question

Spike register S-024-1 (ADR-024 D5): which of the facts Electron reports for a display (`display.id`, `display.label`,
bounds and the rest) stay the same across a reboot, a display-driver update and a dock/undock, on Windows 11, macOS and
Linux (X11 and XWayland)? The stable ones become the inputs of the `displayKey` that `VetaDock` is stored under.

## Setup

- `spikes/S-024-1/displayFacts.cjs`: under Electron, writes one JSON snapshot of `screen.getAllDisplays()` (id, label,
  primary, internal, bounds, workArea, size, scaleFactor, rotation, displayFrequency, colorDepth, detected) and quits
  without opening a window; under Node, compares two snapshots (displays paired by id, else by label; facts that
  changed).
- `spikes/S-024-1/display-facts.md`: the owner's procedure per OS (restart, full shutdown, driver update, undock,
  redock, other port, scale change, primary change).

## Commands

```sh
pnpm exec electron spikes/S-024-1/displayFacts.cjs --label windows-same-boot-1 --out spike-results/S-024-1/windows-same-boot-1.json
pnpm exec electron spikes/S-024-1/displayFacts.cjs --label windows-same-boot-2 --out spike-results/S-024-1/windows-same-boot-2.json
node spikes/S-024-1/displayFacts.cjs compare spike-results/S-024-1/windows-same-boot-1.json spike-results/S-024-1/windows-same-boot-2.json
```

Observed: each snapshot printed `S-024-1: 2 display(s) written to …` and exited 0; the comparison matched both displays
by `id` with no changed fact.

## Results

| OS                                              | Event                                                                            | Displays                           | Matched by                          | Facts changed |
| ----------------------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------- | ----------------------------------- | ------------- |
| Windows 11 Pro 10.0.26200.9457, Electron 44.0.0 | none (two snapshots in one boot)                                                 | 2 external, both `internal: false` | `id` (both)                         | none          |
| Windows 11                                      | restart, full shutdown, driver update, undock/redock, other port, scale, primary | —                                  | pending (owner, `display-facts.md`) | pending       |
| macOS                                           | every event                                                                      | —                                  | pending (owner)                     | pending       |
| Linux X11                                       | every event                                                                      | —                                  | pending (owner)                     | pending       |
| Linux Wayland with XWayland                     | every event                                                                      | —                                  | pending (owner)                     | pending       |

The one Windows observation is a same-boot baseline: it shows the tool works and the facts are stable within one boot.
It says nothing yet about the events the exit criterion names.

## Decision

- **No `displayKey` input is chosen yet.** The exit criterion needs the facts across reboot, driver update and
  dock/undock per OS, and none of those has been observed. ISSUE-286 (docking by display) stays gated on this record.
- When the owner's snapshots arrive, a fact becomes a `displayKey` input on an OS when it stays the same through
  restart, full shutdown, driver update and redock, never moves to another display, and changes only when the physical
  display changes (`display-facts.md` "How the result is read"); facts that change with scale or primary (`bounds`,
  `workArea`, `scaleFactor`, `primary`) can only break ties.

Verdict **partial**: the tool exists and one Windows same-boot baseline is recorded; every event of the exit criterion
is pending on Windows, macOS and Linux.
