# S-021-2 — the OpenCode event that ends a turn

## Question

Spike register S-021-2 (ADR-021 item 4): which event on an `opencode serve` event stream marks a completed turn,
with which field names, at the pinned OpenCode version? Until it is known, OpenCode sessions have `turnEnd: 'none'`.

## Setup

The evidence is a real-CLI recording with the maintainer's own login (`17` §5.5). This issue built:

- `spikes/S-021-2/openCodeTurnEvents.mjs`: over a session's event stream (one JSON event per line, as
  `captureTranscript.mjs --sse` keeps it), how often each event kind occurred, and which kinds occurred exactly once
  per prompt sent. A kind is the event type, with the status for `session.status`. A `message.updated` that carries a
  completion time counts as `message.completed:<role>`, once per message id, because it is sent again on later
  updates. Event names and counts only.
- The cases, in `spikes/SP-06/observer-cases.md`: `two-turns` and `tool-continuation`. A tool step makes two
  assistant messages complete in one turn, so a per-message event cannot pass for a per-turn one.
- `spikes/S-021-2/openCodeTurnEvents.os.test.mjs` (OS lane, synthetic events in the shapes the analyzer reads; they
  are not a claim about OpenCode's real vocabulary).

## Decision

- **`turnEnd` stays `none` for OpenCode (ADR-021 item 4); its ends are `inferred`** (ADR-032 item 5): no finished cue,
  no level-3 notification, no "Turn finished" wording. ISSUE-100 builds that.
- **Passed for an OpenCode version** means: in both cases, one event kind occurs exactly once per prompt, the record
  names it with its fields at that version, and the scrubbed event streams are committed under
  `fixtures/opencode/observer/<version>/`, where the C-20 cases read them. Then `15` §3 records the OpenCode
  `turnEnd: 'reliable'` source with version and date, and ISSUE-100 maps that event. The fixtures may move to the
  `opencode serve` driver's folder when that driver's issue records its own.

Verdict **partial**. The analyzer exists and passes on synthetic input. No OpenCode event stream has been recorded,
and no fixture is committed.
