# Provider terms

DwarfAI-Miners runs each provider's own command-line tool with the person's own login, and the
provider terms that apply are that person's own. This file holds the written evidence the project
keeps about those terms (ADR-008 item 6; NFR-COMP-05): the confirmations the owner obtained from
providers, and the terms review that gates launching Antigravity.

Entries are recorded by the owner only. A confirmation is copied here verbatim, with the date it
was received and the channel it came through.
